# 2026-10-08 초록 바구니 비접촉 정렬 사전 점검

- 사용자는 초록 바구니 배치를 완료했다고 보고했다. 이번 범위는 빈 그리퍼로 바구니 위 공기 간격을 유지하는 **사용자 직접 수동** 정렬 시험의 사전 점검이다. 이후 사용자는 물체를 팔 이동 범위 밖으로 치우고 빈 그리퍼·사람 범위 밖·즉시 중단 준비를 확인했으며 비접촉 수동 1회를 승인했다.
- LeLab 8000 화면은 `Ready`이며 텔레옵 실행 화면이 아닌 시작 화면이다. Mac 8031 판정 화면은 `ROBOT DISABLED`, 약통 검출 0건, 기준 마커 ID0–3과 초록 바구니 ID5만 검출한다. 정면·사선 스트림은 화면상 갱신 중이다. 이는 로봇 좌표나 안전한 경로의 증거가 아니다.
- 정면 영상에는 중앙 초록 바구니 1개와 왼쪽 약통 여러 개, 오른쪽 가위가 보인다. 사선 영상에도 바구니와 오른쪽 가위가 보인다. 이 물체들이 팔 이동 범위 밖인지는 영상으로 확정할 수 없다.
- 새 정면 영상에서는 약통 다수가 사라졌으나 왼쪽에 물체 1개와 오른쪽 가위가 여전히 영상 가장자리에 보인다. 현장 사용자는 이 물체들이 이동 범위 밖이라고 확인했다. 영상만으로 실제 최소 간격은 계산할 수 없다. 승인 후 리더·팔로워 시작 자세를 맞추고 기존 LeLab 텔레옵을 **사용자가 직접** 켠 뒤, 리더는 움직이지 않은 상태에서 이상 움직임이 없는지 보고하도록 요청했다.
- 사용자는 직접 텔레옵을 켰고 이상 움직임이 없다고 보고했다. 빈 그리퍼를 초록 바구니 중앙 상공에서 긴 방향에 맞춰 비접촉 정지했다고 보고했다. 그러나 정면 프레임에서 두 손가락 사이 폭은 화면 좌우이고 바구니 긴 축은 화면 상하로 보인다. 원근과 링크 형상으로 실제 3D 방향을 확정할 수는 없으나 **긴 축 정렬이 확인되지 않아** 하강을 금지했다. 손목을 돌리기 전에 사용자가 먼저 손끝을 바구니 테두리에서 충분히 위로 퇴피해 멈추도록 요청했다. 종료/퇴피 결과는 답변 대기 중이다.
- 사용자는 공중 퇴피·무간섭과 공중 손목 방향 변경·정지를 보고했다. 새로 갱신된 정면 영상에서도 두 손가락의 벌림 방향은 좌우, 바구니 긴 축은 상하로 보여 방향 변경 효과가 영상에서 확인되지 않았다. 사선 화면만으로 높이·간격은 정량 측정할 수 없다. 추가 접근/하강을 중단하고 사용자 직접 비접촉 퇴피·텔레옵 종료를 요청했다.
- 사용자는 비접촉 퇴피·종료와 접촉/걸림/이상 움직임 없음을 보고했다. 종료 뒤 새 정면·사선 영상에는 그리퍼가 바구니에서 떨어져 있다. LeLab UI는 텔레옵 페이지에 머물며 읽기 전용 `/teleoperation-status`는 이 세션의 네트워크 차단으로 재조회하지 못했다. **서버 측 종료는 미검증**이며 사용자 종료 보고와 영상상 퇴피만 확인했다. 바구니 안으로 진입·개방·자동 동작은 수행하지 않았다.
- 다음 검증 후보는 텔레옵이 실제 종료된 상태에서 초록 바구니를 중앙 위치에 둔 채 긴 축이 정면 화면의 좌우가 되도록 수동으로 90° 회전 배치해, 같은 그리퍼 벌림 방향과의 정렬 여부를 카메라로만 재점검하는 것이다. 이는 기존 고정 배치의 승인이나 자동 동작 변경이 아니며, 새 수동 시험은 별도 현장 확인·승인이 필요하다.
- 사용자가 바구니를 재배치했다. 새 정면 영상에서 바구니 긴 축이 좌우이고 ID5가 검출된다(`table_xy_mm` 약 111.184, 230.516). 사선 영상에도 바구니가 보이며 Mac 8031은 여전히 `ROBOT DISABLED`, 기준 ID0–3과 ID5 검출, 약통 검출 0건이다. LeLab 메인 화면은 `Ready`이나 서버 `/teleoperation-status` API는 현재 접근 경로에서 재조회하지 못했다. 이전 정면 영상의 손가락 벌림 좌우 방향과 바구니 긴 축이 화면상 나란해졌다는 **배치 관찰**만 확인했다. 실제 통과 여유나 로봇 경로는 미검증이다. 새 비접촉 수동 1회에 대한 현장 안전 확인·승인을 요청했다.
- 사용자는 텔레옵 꺼짐, 사람·가위·약통의 이동 범위 밖 배치, 리더·팔로워 시작 자세, 즉시 중단 준비를 확인하고 비접촉 수동 1회를 승인했다. 기존 LeLab 텔레옵을 직접 켰고 시작 직후 이상 움직임이 없다고 보고했다. 빈 그리퍼를 초록 바구니 중앙 상공에 긴 축 방향으로 맞춰 비접촉 정지했다고 보고했다. 새 정면 영상에서 손가락 벌림 방향과 바구니 긴 축은 모두 좌우로 보인다. 다만 손끝은 뒤쪽 테두리 근처에 투영되어 입구 중앙·실제 높이 간격은 영상만으로 확정하지 않았다. 바구니 안으로 진입하거나 그리퍼를 개폐하지 않았다.
