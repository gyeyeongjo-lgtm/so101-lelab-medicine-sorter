- 기존 `audit_teleop_trace.py`의 SHA/JPEG 검증·URDF 한계 거부·`use_for_replay=false`를 유지하면서, 0.01 rad 첫 자세 이탈 **전/후** 초과 수·최종 초과 시점만 추가했다. 0.01 rad는 방송값의 구간 분류 기준일 뿐 물리 움직임 시작 판정이 아니다. 어느 표본도 삭제하거나 한계를 넓히지 않았다.
- 기존 calibration 오프라인 감사에는 설치 `DEGREES` 변환식 `rad=(raw−(min+max)/2)×2π/4095`을 역산한 관측 raw 범위와 정수 step 잔차를 추가했다. 이 수치는 현재 레지스터·실제 명령값이 아니며 물리 영점·회전 방향을 입증하지 않는다.

- 첫 두 **비접촉** 기록에서는 Elbow `URDF_LIMIT_MISMATCH`가 주로 시작 자세에 있었고 초반 이탈과 짧게 겹쳤다. 하지만 별도 **실제 투입** 기록은 Elbow 초과가 경로 말미까지 남고 Wrist_Pitch도 이동 중 초과했다. 그러므로 ‘초기 샘플만 제거하면 경로 적합’이라는 가설은 반증됐다. 현재 URDF 상한은 Elbow `+1.5708 rad`(+90°), Wrist_Pitch `+1.65806 rad`(+95°). 최대 관측 Elbow `+1.685489 rad`(+96.571°), Wrist_Pitch `+1.749932 rad`(+100.264°)를 새 제한으로 채택하지 않는다.
- 세 기록의 팔 5관절 방송값은 저장된 follower calibration 범위의 중간점을 이용해 역산하면 모두 정수 raw step과 일치한다(최대 반올림 잔차 0.0 step). C 상공 Elbow 관측 최대 +96.571°는 추정 raw 3082로 파일/이전 장치 제한 3087보다 5 step 낮다. 이는 사용 중인 `DEGREES` 수치 변환과 rad 방송의 **내적 일관성** 증거이며, 실제 물리 영점/부호·URDF axis 정합이나 모터 명령/응답 일치를 증명하지 않는다. 단순 도↔rad 단위 오류만으로 90° 대 96.571° 차이를 설명할 근거는 없다.
- 정확한 설치 URDF 경로·SHA/한계는 이전 Jetson 읽기 전용 점검의 `frontend/dist/so-101-urdf/urdf/so101_new_calib.urdf`, SHA `443d38d756e01bac7d3455b24430047ddc6427105e0d3454b2003116f5f67236`, Elbow `−1.74533…+1.5708 rad` 스냅샷으로 확인된다. 이번 현재 설치 재해시는 SSH 인증 실패로 `NOT_VERIFIED`. 저장소에 Xacro·MoveIt joint limits 설정은 없고, 이전에 조사한 수동 `get_action→send_action→Goal_Position`에 URDF·MoveIt·IK·충돌 검사는 없다. **실제 거부 예외는 기록되지 않았고** 이번 문자열은 오프라인 감사의 재생 차단이다. 자동 추론 경로 전체는 별도 확인 대상이다.

## 첫 최소 시연 방식 결정

- **A: 고정 배치 + 검증된 전체 관절 경로 선택을 추천**한다. 사용자 고정 배치와 C→빨강 ID4 수동 집기·놓기·퇴피 관찰 및 3시야/관절 기록이 있다. 첫 한 종류·한 목적지에는 World→Base/TCP/IK 정확도 확보가 필수는 아니다. 그러나 기존 방송 기록은 명령 궤적이 아니고 카메라 노출시각 동기가 없으며, 시작·이동·놓기·퇴피의 충돌 여유·재현성·관절 한계가 승인되지 않았다. 현재 자동 재생 구현/검증으로 간주하지 않는다.
- **B: 영상 좌표 + World→Base/TCP + IK/경로 생성**은 가변 배치 확장성은 높지만 기존 좌표 적합이 잔차/조건수 기준에 실패했고, TCP·바구니 입구 3D·IK/충돌 경로 검증이 없다. 첫 C→ID4 시연에 필요한 미해결 요소가 A보다 많다. A를 선택하더라도 배치 변화 검사, 리더/팔로워 시작 자세 일치, 접근·집기·이동·놓기·퇴피의 완전 연속 경로, 자체/환경 충돌 및 경계 여유, 중단·실패 복구를 생략하지 않는다.
- 다음 **한 단계**는 Jetson의 현 설치 URDF와 LeLab 관절 매핑·calibration `homing_offset`/`drive_mode`, follower 실제 `Present_Position`의 같은 시각 읽기 전용 자료를 확보해 모델 제한 오설정과 영점/부호 매핑 오류를 가르는 것이다. 합격 기준은 설치 SHA/제한과 레지스터·방송 변환이 재현되고, 각 관절명·부호·영점의 대응이 문서화되는 것. 제조사 SO-101 조립체 허용 범위 또는 현장 검증 범위가 없으면 숫자 제한 변경안은 보류한다. 실제 모터 명령·토크·서비스·USB 변경은 별도 현장 확인과 범위별 승인 전 `NOT_RUN`.
