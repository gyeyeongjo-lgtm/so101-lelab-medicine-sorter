# 2026-10-08 현 고정 배치의 경유 자세 재사용 감사·캡처 준비

## 판단 기준과 기존 자료

- 자동 집기의 주 병목인 World→Base/TCP는 기존 P5 자료의 움직이는 두 손가락 접촉점·독립 검증 문제로 `REJECTED`다. 같은 P5를 더 촬영해 승인으로 간주하지 않는다. 사용자가 세 출발 슬롯과 바구니 자세를 고정한다고 확인했으므로, **비접촉 수동 경유 자세를 새 배치에서 기록하고 비교하는 M4b 대안**을 준비한다. 이는 좌표 변환 승인이나 자동 재생 승인이 아니다.
- Git 제외 `.local/fixed-slot-waypoints/`의 기존 35개를 사용자 현 고정 배치 기준 `.local/basket-opening-captures/20261008T022818_PV95dh/ceiling.jpg`와 기존 `audit_fixed_basket_scene.py`로 오프라인 대조했다. 라벨은 PARK 7·SOURCE1_HOVER 2·BASKET4_HOVER 26뿐이며 ID5/6 목적지 라벨은 없다.
- 35개 중 25개는 ID5/6 또는 ID2/5/6 누락으로 `INDETERMINATE`, 나머지 10개는 `MARKER_LAYOUT_CHANGED`였다. 10개에서 바구니 마커 최대 화면 이동은 10.662–10.993 px였다. **현재 배치와 일치가 확인된 옛 waypoint는 0개**다. 이것은 픽셀 배치 감사이지 3D 간섭 검증이 아니다. 옛 원본은 수정·삭제하지 않았고 전부 `use_for_replay=false` 그대로다.

## 읽기 전용 캡처 코드 준비

- 기존 `teach_capture_web.py`에 현 고정 슬롯용 `SOURCE_A_HOVER`/`SOURCE_B_HOVER`/`SOURCE_C_HOVER`와 ID5/6용 `BASKET5_HOVER`/`BASKET6_HOVER` 라벨만 추가했다. 기존 `PARK`·`SOURCE1_HOVER`·`TRANSFER_HOVER`·`BASKET4_HOVER`·`BASKET4_RELEASE`는 호환성을 위해 유지했다. 새 라벨은 **비접촉 상공 관찰**이며 집기·놓기·안전 높이·목표 좌표를 뜻하지 않는다.
- 저장 로직의 신선한 관절 15개·정면/사선 프레임·안정성·현장 확인 두 항목·LeLab 텔레옵 활성 확인을 변경하지 않았다. 결과는 `use_for_replay=false`, `robot_enabled=false`, `motion_authorized=false`이며 제어 API가 없다. UI와 백엔드 라벨 일치 회귀 시험을 추가했다.
- 첫 `.venv` 시험은 샌드박스가 로컬 임시 테스트 서버 bind를 막아 13개 중 4개가 `PermissionError`로 끝났다. 동일 코드/조건을 로컬 포트 허용 실행으로 재검사해 13/13 통과, 추가 UI 일치 시험을 포함해 14/14 통과했다. 이 실패는 로봇·카메라 오류로 해석하지 않는다.
- `FIXED_SLOT_WAYPOINTS.md`의 과거 ID4 전용 설명을 이력으로 명시하고 현 A/B/C·ID4/5/6 캡처 라벨과 라이브 미적용 상태를 반영했다. 최종 `git diff --check` 통과. 최종 `.venv` 14개 재실행도 로컬 포트 허용 환경에서 통과했고, 제한 환경의 포트 권한 오류 4건은 재현됐다.
- 현재 Mac 8030은 기존 `teach_capture_web.py` 프로세스, 8031은 8030 캐시를 쓰는 약통 판정 페이지임을 PID/실행 인자로 확인했다. 처음 일반 `ps` 조회는 샌드박스가 막았고 허용된 읽기 전용 재조회로 확인했다. **실행 중인 8030은 재시작하지 않았다.** 따라서 새 라벨은 저장소에 준비된 상태일 뿐 라이브 8030 UI에는 아직 적용되지 않았다. 8030 재시작은 8031 카메라 입력을 잠시 끊을 수 있어 실제 새 캡처 시험 직전에만 별도 사전 점검 후 수행한다.

## 다음 현장 시험의 최소 범위

- 우선 후보는 **한 병의 출발 슬롯 상공과 해당 바구니 상공에 정지한 비접촉 두 자세**를 같은 고정 배치에서 사용자 기존 LeLab 텔레옵으로 기록하는 것이다. 집기·바구니 내부 진입·자동 재생은 포함하지 않는다. 어떤 병을 먼저 할지, 현재 물체·바구니 배치와 관찰기 신선도, 새 현장 안전 확인과 그 1회의 승인을 확인한 뒤에만 진행한다.
- 새 자료라도 정지 관절 방송·수신시각 사진만으로 두 자세 사이의 **연속 경로**나 실제 손끝·테두리 간격은 검증되지 않는다. 경유 자세의 반복성·장면 마커 일치와 별도로 실제 경로 검증이 필요하다. 자율 이동/재생 `BLOCKED/NOT_RUN`, 이슈 API `NOT_RUN`, 원격 push `NOT_PUSHED`.
