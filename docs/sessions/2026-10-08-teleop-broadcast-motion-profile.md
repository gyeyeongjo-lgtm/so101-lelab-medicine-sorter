# 2026-10-08 저장된 수동 관절 방송의 시간·변화량 오프라인 점검

## 범위와 방법

- Git 제외 `.local/teleop-traces/`의 관절 기록 9건을 읽기 전용으로 검사했다. 기존 무결성 검사로 원본 SHA-256·표본 수·타임스탬프·포함된 영상 해시를 확인하고, 인접 **방송 표본**의 값 차이와 `source_unix` 간격을 계산했다. 영상은 모두 완전 동기 연속 경로 증거가 아니다.
- [오프라인 검사기](../../scripts/audit_teleop_motion_profile.py)는 `use_for_replay=false`, `robot_enabled=false`, `motion_authorized=false`를 고정한다. 파일·서비스·USB·모터·토크·캘리브레이션은 변경하지 않았다. 유한차분은 실제 모터 속도 측정이 아니고 표본 사이 경로·간섭을 보이지 않는다.

## 판정과 다음 단계

`PASS (broadcast integrity/profile) / REPLAY BLOCKED`: 방송 간격·변화량을 수치로 남겼지만, 실제 모터 명령/응답, 표본 사이 간섭, 바구니 내부 여유, 안전한 표준 시작 자세는 검증되지 않았다. [캘리브레이션 경계 대조](2026-10-08-calibration-trace-envelope-offline.md)의 경계 근접과 설치 URDF 불일치도 그대로다. 따라서 자동 재생·자율 투입은 `NOT_RUN`이다. 다음은 오프라인으로 TCP/World→Base와 바구니 입구 중심·자세의 검증 요건을 정리하고, 실제 이동 시험은 별도 현장 안전 확인·승인 뒤에만 한다. 이슈 API `NOT_RUN`, 원격 push `NOT_PUSHED`.

관련 단위 테스트 24개 통과. 첫 테스트 실행은 `tests`가 Python 패키지가 아닌데 패키지 경로로 지정해 import 오류가 났고, `unittest discover`로 수정했다. 새 테스트의 첫 실행에서는 딕셔너리 내포 문법 오류가 있었고 수정 후 24개가 통과했다.
