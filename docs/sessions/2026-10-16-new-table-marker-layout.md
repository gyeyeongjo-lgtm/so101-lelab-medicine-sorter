# 2026-10-16 새 작업대 ArUco 중심 배치

## 사용자 확정 입력

- Dictionary: `DICT_4X4_50`
- ID0–3 검은 사각형 크기: `70 mm`
- 측정 방식: 검은 사각형 중심-중심
- 거리: `0-1=530`, `1-2=320`, `2-3=516`, `3-0=323`, `0-2=610`,
  `1-3=605 mm`
- 사용자 현장 판단: 현재 여백으로 인식이 잘되므로 배치 유지

## 평면 좌표 적합

ID0을 원점, ID1 방향을 +X로 고정하고 여섯 실측 거리를 동일 가중치로
최소제곱 적합했다.

```json
{
  "0": [0.0, 0.0],
  "1": [527.324, 0.0],
  "2": [524.108, 318.309],
  "3": [10.865, 321.156]
}
```

- distance residual RMS: `2.600 mm`
- maximum absolute residual: `3.196 mm`

`configs/system.example.json`/문서에 입력했다. 이는 현재 물리 배치를 여섯
거리와 동시에 정합시키는 테이블 평면 좌표이며, Astra live pixel→table
재검증과 새 `T_B_W` 검증을 대체하지 않는다.

## 약통 마커

- ID7: 작은 약통 C
- ID8: 중간 약통 B
- ID9: 큰 약통 A
- 약통용 검은 사각형: `30 mm`

실제 인쇄물 실측·약통 부착·Astra live ID7–9 검출은 `NOT_RUN`.
로봇 `T_B_W`, TCP, 경로, 모터 동작은 `NOT_RUN/NOT_VERIFIED`.
