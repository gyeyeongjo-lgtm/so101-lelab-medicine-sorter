# 2026-10-08 그리퍼 설계 메쉬 외접 폭 오프라인 점검

## 범위와 첫 발견

사용자는 다음 단계의 그리퍼-바구니 통과 여유를 확인해 달라고 요청했다. Jetson에 설치된 LeLab URDF `so101_new_calib.urdf`의 SHA-256은 기존 기록과 같은 `443d38d756e01bac7d3455b24430047ddc6427105e0d3454b2003116f5f67236`이다. 그러나 설치 `frontend/dist/so-101-urdf/meshes/*.stl`은 실제 삼각형 메쉬가 아닌 약 130바이트 Git LFS 포인터였다. 이 파일들만으로 외접 폭을 계산하면 잘못된 결과가 난다.

Jetson의 기존 uv 캐시에는 실제 바이너리 STL이 있었다. `moving_jaw_so101_v1.stl`과 `wrist_roll_follower_so101_v1.stl`의 SHA-256이 설치 LFS 포인터의 oid와 각각 `785a9dde…`, `4b17b410…`으로 일치함을 읽기 전용으로 확인했다. 캐시·설치 파일은 수정하지 않았다.

## 계산

실제 STL 삼각형 좌표에 URDF `gripper`·`jaw` visual 원점과 `Jaw` joint 원점/회전을 적용해 `gripper` 프레임의 모델 축정렬 외접 상자를 계산했다. `gripper`의 모터·follower 메쉬와 단일 `jaw` 메쉬가 포함된다. 사용자 직접 시연의 사선 프레임에 가장 가까운 관절 방송의 Jaw 값은 B 입구 부근 약 0.43259 rad, C 집은 상태 약 0.21469 rad, C 개방 후 약 0.54582 rad다. 카메라·관절 시각은 Mac 수신시각 근사이며 노출시각 동기화가 아니다.

| 기존 시연 표본 | Jaw | 모델 가로 X 외접 폭 | 모델 Y 외접 폭 | 현장 보고 약 85 mm 짧은 입구와 X 폭 차이 |
| --- | ---: | ---: | ---: | ---: |
| B 입구 부근 | 0.43259 rad | 83.7 mm | 52.0 mm | 1.3 mm 총합(중앙 가정 각 약 0.7 mm) |
| C 집은 상태 | 0.21469 rad | 71.7 mm | 52.0 mm | 13.3 mm 총합(각 약 6.7 mm) |
| C 개방 후 | 0.54582 rad | 91.6 mm | 52.0 mm | 보고 입구보다 6.6 mm 큼 |

이 비교는 **모델 X축을 바구니의 짧은 약 85 mm 방향과 평행하게 둔 가정**이다. 실제 손목 방향, 바구니별 입구 편차, 병을 포함한 외접 형상, 카메라 장착물, 팔 링크의 경로를 포함하지 않는다. 특히 URDF에는 단일 구동 `Jaw` 링크만 있지만 사용자는 현장에서 두 손가락이 함께 움직인다고 확인했다. 따라서 이 설계 모델은 실제 그리퍼 외접 폭을 완전히 표현한다고 볼 수 없고, 위 수치는 실제 통과 여유·충돌 판정이 아니다.

## 판정과 다음 단계

가정하에서도 B 자세의 양옆 여유가 약 0.7 mm로 매우 작고 C 개방 자세의 모델 폭은 보고된 짧은 입구보다 넓다. 기존 수동 성공 보고와 모순이라고 단정하지 않는다. 그리퍼 방향이 긴 입구 축과 달랐거나, 실제 메커니즘/입구가 모델과 다를 수 있다. 기존 B/C 관절 방송에서 Jaw가 커지는 시각을 사선 영상과 수신시각으로 근사 대조하면 손가락이 각 바구니 입구 부근에 보인다. 원근·가림 때문에 테두리 위인지 안인지 정량 판정할 수 없으며, **개방이 완전 퇴피 후에만 이뤄졌다고 가정하지 않는다**. 사용자 현장 무간섭 보고는 그대로 유지한다. 자동 이동에는 실제 손가락·장착물의 외접 폭과 투입/개방/퇴피 중 자세별 테두리 여유를 따로 확인해야 한다. 모델 수치만으로 허용 경로를 만들거나 기존 시연을 재생하지 않는다.

순수 2D 배치 가정으로는 모델 X 폭을 바구니의 명목 긴 128 mm 방향에, 모델 Y 폭을 보고된 짧은 약 85 mm 방향에 맞추면 B 자세의 계산상 간격은 각각 긴 방향 양옆 약 22.2 mm·짧은 방향 각 약 16.5 mm가 된다. C 개방 자세의 긴 방향 양옆은 약 18.2 mm, 짧은 방향 각 약 16.5 mm다. 이는 **검증 후보 방향**일 뿐 실제 긴 내부 폭·Wrist_Roll 자세, 병 기울기, 손목·카메라 부착물 및 3D 삽입 경로가 빠져 있다. 새 회전 동작을 제안하거나 실행하지 않는다.
