# 프로젝트 로드맵

| 단계 | 목표 | 현재 상태 / 진입 조건 |
|---|---|---|
| M0 | LeLab 녹화·ACT 기준선 | 과거 실험 완료, 실제 집기 성능은 미달 |
| M1 | Astra RGB·intrinsic·ArUco 작업대 | RGB intrinsic과 ID0–6 live homography 검증 완료 |
| M2 | Astra RGB–Depth 정합 진단 | OpenNI2 정합·300-frame depth 진단 완료 |
| M3 | Camera 2.5D와 World frame | 300-frame 안정성 통과; full 3D PnP는 잔차 기준 미달로 제어에 사용 금지 |
| M4 | World→Robot Base 등록 | 첫 네 P5 자세와 추가 후보의 오프라인 TCP 진단은 일부 수치 통과지만 물리 접촉 검증·사전 지정 독립 holdout 미완료. World→Base 변환은 계속 거부 |
| M4b | 고정 슬롯 waypoint 시연 경로 | 큰 A→파랑 ID6, 중간 B→초록 ID5, 작은 C→빨강 ID4 사용자 직접 수동 투입 각 1회 성공 보고와 종료 영상 확인. A/B/C 상공 비접촉 접근도 관찰했으나 A/C는 기존 픽업 ROI 밖이며 C 접근 기록은 퇴피 전체가 빠졌다. B/C 투입 관절·정면·사선 표본 무결성은 통과했지만 설치 URDF 상한 불일치와 동기 연속 영상·경로 여유 미검증으로 자동 재생 거부. 동일 조건 반복성·자동 인식→집기→투입 `NOT_RUN` |

| M8 | 제한된 VLM 보조 제안 | 허용 목록과 사람/규칙 확인; 직접 모터 명령 금지 |

2026-10-07 현재 활성 범위는 M4의 **표시한 움직이는 손가락 끝**에 대한 TCP/World→Base 진단과 M4b의 사용자 직접 수동 시연 관찰이다. P5 후보의 사후 수치 통과와 A/B/C 상공 비접촉 도달은 동일 물리 접촉점·높이·연속 경로의 독립 검증을 대신하지 않는다. TCP와 World→Base는 아직 **승인되지 않았고 자동 이동은 비활성**이다. M4가 통과하기 전 M6–M7 실제 자동 이동은 진행하지 않는다.

진행률은 기간 예측이 아니라 2026-10-07 현재의 거친 단계별 판단이다. 빈 약통·모형을 한 바구니에 안전하게 옮기는 **연구용 시연은 약 35–45%**, VLM 보조 제안·사람 승인·실제 약품 확인까지 포함한 **최종 목표는 약 20–30%**다. A/B/C 비접촉 접근 관찰은 도달 가능성 증거를 추가했지만 실제 자동 집기·투입 게이트를 넘기지 못해 이 범위를 올리지 않는다. 카메라·ArUco·YOLO·웹 관찰은 작동하지만 로봇 좌표 등록·제한 이동·집기/투입 반복 검증이 남았고 후반 단계가 작업량과 안전 검증의 대부분이다. 이 수치는 성능 지표가 아니며 새 시험 결과에 따라 달라진다.

가장 빠른 안전 경로는 (1) 실제 구조에 맞는 TCP/기준점 모델을 정의해 독립 검증하고, (2) 그 기준을 고정한 World→Base 다점 fit과 미사용 지점 holdout을 통과시키고, (3) 별도 현장 승인 아래 빈 작업대의 높은 Z 제한 이동부터 단계적으로 시험하는 것이다. 16:01 KST 새 P5 세 건에서는 두 건이 기존 고정 기준선 수치 통과, 한 건이 실패했고 후속 접촉 주장 자료 15건의 Z 잔차가 전부 같은 방향이다. 따라서 **현재 방식으로 P5만 계속 반복 촬영하지 않는다.** 사용자는 오픈그리퍼의 두 손가락이 함께 움직인다고 확인했다. 이전의 “반대편 고정 손가락” 제안은 철회한다. 다음은 손가락 구동부가 아닌 비구동 강체 기준점 또는 영상 기반 hand-eye 방법의 실현 가능성을 검토한다. 이는 기존 캡처를 자동 재라벨링하거나 모션을 승인한다는 뜻이 아니다. 초기 실험은 빈 용기와 가상 라벨만 사용하며, VLM 결과를 직접 약품 선택이나 저수준 모터 명령으로 연결하지 않는다.
