# 프로젝트 로드맵

| 단계 | 목표 | 현재 상태 / 진입 조건 |
|---|---|---|
| M0 | LeLab 녹화·ACT 기준선 | 과거 실험 완료, 실제 집기 성능은 미달 |
| M1 | Astra RGB·intrinsic·ArUco 작업대 | RGB intrinsic과 ID0–6 live homography 검증 완료 |
| M2 | Astra RGB–Depth 정합 진단 | OpenNI2 정합·300-frame depth 진단 완료 |
| M3 | Camera 2.5D와 World frame | 300-frame 안정성 통과; full 3D PnP는 잔차 기준 미달로 제어에 사용 금지 |
| M4 | World→Robot Base 등록 | 첫 네 P5 자세와 추가 후보의 오프라인 TCP 진단은 일부 수치 통과지만 물리 접촉 검증·사전 지정 독립 holdout 미완료. World→Base 변환은 계속 거부 |
| M5 | 약통 검출·안전한 dry-run | YOLO live smoke·ArUco/basket 표시 통과; 약통 높이·grasp offset·limits·목표 안정성 필요 |
| M6 | 제한된 실제 이동 | 별도 안전 승인 후 높은 Z에서 XY-only부터 검증 |
| M7 | 분류→집기→이동→놓기 | descend/grip/lift/place와 실패 복구 검증 |
| M8 | 제한된 VLM 보조 제안 | 허용 목록과 사람/규칙 확인; 직접 모터 명령 금지 |

2026-10-02 현재 활성 범위는 M4의 **표시한 움직이는 손가락 끝**에 대한 P5 단일점 TCP 진단이다. 새 저장본 10개 중 한 건은 잘못 저장됐을 가능성이 높아 원본 보존·검증 제외했고, 수치 통과 후보 3개는 현장 접촉 보고가 있으나 영상으로 동일 물리점의 접촉을 독립 확인하지 못했다. 기존 네 자세에 대한 세 후보 독립 오차는 4.45/7.73/7.60 mm이며, 세 후보를 서로 바꿔 holdout으로 둔 탐색 검증은 2/3 통과·1/3 경계 초과다. 이 후보들은 수치로 선별했으므로 그 결과를 사전 지정된 독립 검증으로 주장하지 않는다. TCP와 World→Base는 아직 **승인되지 않았고 자동 이동은 비활성**이다. M4가 통과하기 전 M6–M7 실제 이동은 진행하지 않는다.

진행률은 기간 예측이 아니라 2026-10-02 현재의 거친 단계별 판단이다. 빈 약통·모형을 한 바구니에 안전하게 옮기는 **연구용 시연은 약 35–45%**, VLM 보조 제안·사람 승인·실제 약품 확인까지 포함한 **최종 목표는 약 20–30%**다. 카메라·ArUco·YOLO·웹 관찰은 작동하지만, 로봇 좌표 등록·제한 이동·집기/투입 반복 검증이 남았고 후반 단계가 작업량과 안전 검증의 대부분이기 때문이다. 이 수치는 성능 지표가 아니며 새 시험 결과에 따라 달라진다.

가장 빠른 안전 경로는 (1) 기존 자료의 접촉 품질·기구학을 검수해 TCP를 독립 검증하고, (2) 그 TCP를 고정한 World→Base 다점 fit과 미사용 지점 holdout을 통과시키고, (3) 별도 현장 승인 아래 빈 작업대의 높은 Z 제한 이동부터 단계적으로 시험하는 것이다. 첫 두 단계는 오프라인 분석을 최대한 먼저 진행한다. 초기 실험은 빈 용기와 가상 라벨만 사용하며, VLM 결과를 직접 약품 선택이나 저수준 모터 명령으로 연결하지 않는다.
