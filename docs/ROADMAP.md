# 프로젝트 로드맵

| 단계 | 목표 | 진입 조건 |
|---|---|---|
| M0 | LeLab 녹화 복구 | 녹화·저장·재로딩·서비스 재시작 검증 |
| M1 | 빈 약통 하나의 시연 수집 | 카메라·task·성공 기준 일관성 |
| M2 | 모방학습 기준 정책 | 계산 자원, 분리 평가 데이터, 실패 유형 기록 |
| M3 | ArUco 대상·위치 식별 | marker 매핑과 카메라/좌표 보정 |
| M4 | 제한된 VLM 작업 선택 | 허용 목록, 불확실성 시 사람 확인 |
| M5 | 분류→집기→이동→놓기 통합 | 동작 한계와 실패 복구 체크리스트 |

현재 범위는 M0뿐이다. 초기 실험은 빈 용기와 가상 라벨을 사용하며 VLM이 저수준 모터 명령을 직접 만들지 않는다. 실제 약품의 정체성·복용·용량 판단으로 확대하지 않는다.
